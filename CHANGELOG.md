# Changelog

This project follows [semantic versioning](https://semver.org/). Until 1.0, a minor version may
change the library's API. Changes to the format itself are listed in
[SPEC.md §14](SPEC.md#14-versioning-and-changelog).

## 0.1.0 — first public release

Reads and writes notebooks at **DunneNote Format 0.18 (draft)**: schema 18, the schema of
DunneNote 0.9.

**Specification**
- `SPEC.md`: the complete format, with conformance levels, bundle layout, the SQLite profile and
  version gate, table-by-table semantics, payloads, roles, archive, tags, the search index, a
  writer checklist and the versioning policy.
- `schema/v18.sql`: the normative schema, generated by DunneNote.
- `fixtures/`: six golden notebooks written by DunneNote itself, with `expected.json`.

**Library (`dunnenote-format`)**
- Open a notebook read-only with the version and manifest gates (schema 19 read-only; older
  and newer refused; `format_version` parsed as a semantic version, exactly as DunneNote parses
  it), without taking DunneNote's lock.
- Read the page tree and every canvas kind: rich text, sketches, pictures and their markup,
  Data Tables and Editable tables, calendars with events and attendees; canvas groups, captions,
  forms, templates, archive state, tags, aliases and metadata; blobs.
- `verify`: quick and full health checks (SQLite integrity, foreign keys, tree, reference
  counts, blob files and hashes, content rows, tables, roles, search index).
- Export to Markdown (with pictures and sketches as SVG), CSV and JSON (`export_version` 1).
- Write, following the writer checklist, each change in one transaction:
  - create notebooks; add sections and pages;
  - write rich text (from a ProseMirror document, Markdown or plain text), sketches, pictures,
    picture markup and canvas groups;
  - write tables (import CSV or JSON, or start a blank Editable table; add, rename, move and
    delete columns and rows; set cells);
  - import calendars from `.ics`;
  - write forms (fields, new form, submit to an answers table with carrier canvases), captions
    and page settings;
  - write templates (make, and new page from);
  - archive and retrieve pages, sections, notebooks and canvases (with `.archive/` snapshots);
  - write tags, aliases, merges and metadata, folded with fold v1.

**Command-line tool (`dnfmt`)**
- `inspect`, `ls`, `cat`, `verify`, `export --md|--csv|--json`.
- `new`, `add-section`, `add-page`, `add-canvas rich-text|sketch|picture|table|calendar`,
  `table`, `form`, `caption`, `template`, `archive`, `retrieve`, `tag`, `meta`.

**Testing**
- Every golden notebook reads back exactly as DunneNote read it.
- DunneNote's own code opens notebooks written by this library, health-checks them with no
  findings, and reads back what was written.
- Property tests feed generated and mutated input to every parser of untrusted input (rich
  text, sketches, CSV, JSON, `.ics`, positions, fold v1, settings merges). They also run random
  sequences of writes that must leave a notebook which verifies clean.
